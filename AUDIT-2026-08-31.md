# 🟠 HIGH

## H-1. Octagon: bitta user ikkita PARALLEL match'ga tushib ketadi

**Muammo:** `joinQueue` re-join'da eski entry queue'dan o'chirilmaydi (`queue.delete(userId)` yo'q);
`joinQueue` ↔ `joinDuel` bir-birining kutish holatini tozalamaydi; `startMatch` ikkala o'yinchi
band emasligini tekshirmaydi.

**Oddiy tilda:** Futbolchiga navbatga yozilgan edi, u boshqa jamoaga yozilganda eski yozuvi
o'chirilmay qoladi — natijada ikki o'yinda bir vaqtda "qatnashadi".

**Oqibat:**
- Hiylagar 1 telefonda 2 match o'ynab ikkalasidan g'alaba yig'adi (win-farm);
- reconnect race'ida oddiy user tasodifan 2 matchga tushib qoladi → o'yin buziladi.

**Fayl:qator:**
- `server/octagon.ts:752-758` — re-join'da `queue.delete(userId)` yo'q
- `server/octagon.ts:761-767` — joiner eski entry'si queueTimer=null bilan queue'da qoladi
- `server/octagon.ts:709-740` — `joinDuel` queue entry'ni tozalamaydi
- `server/octagon.ts:356-398` — `startMatch` `playerToMatch` guard'siz

**Fix:**
1. `joinQueue`da `existing` bo'lsa darhol `queue.delete(userId)`;
2. `joinQueue` va `joinDuel` bir-birining pending holatini tozalasın;
3. `startMatch` boshiga `if (playerToMatch.has(p1) || playerToMatch.has(p2)) return` guard;
4. Regression test: `tests/unit/server/` yoki integration WS test'ga qo'shish.

# 🟡 MEDIUM

## M-1. WS per-IP connection limit YO'Q

**Muammo:** `maxConnsPerUser=3` faqat auth'dan KEYIN ishlaydi; upgrade paytida IP tekshiruvi yo'q.

**Oqibat:** 1 IP'dan minglab parallel WS upgrade → file descriptor / xotira exhaustion
(Render instance juda nozik).

**Fayl:qator:** `server/octagon.ts:856`, `server/index.ts:21,60-63`

**Fix:** per-IP concurrent cap (~20) + global unauthed-connection cap; upgrade'da IP token-bucket.

---

## M-2. `online_players` broadcast — DB yuklama amplifikatsiyasi

**Muammo:** har `get_online` = alohida DB query (kesh yo'q); har connect/disconnect'da
TO'LIQ ro'yxat DB'dan o'qilib barcha socketlarga yuboriladi (O(N²) egress).

**Oqibat:** connect/disconnect flap → soniyasiga ~4 to'liq DB query; N=1000'da har broadcast
~100KB × 1000 socket ≈ 100MB egress.

**Fayl:qator:** `server/octagon.ts:239-290`, `927-938`

**Fix:** broadcast'ni 15–30s interval-based qilish; ro'yxatni 5s keshlash; `get_online`'ga
per-user limit (1/10s); mumkin bo'lsa delta-broadcast.

## M-3. Duel mukofotlarida anti-farm YO'Q (kolluziya)

**Oqibat:** kunlik/haftalik/oylik duel leaderboard va `octagon10` yutug'i soxtalashadi.
